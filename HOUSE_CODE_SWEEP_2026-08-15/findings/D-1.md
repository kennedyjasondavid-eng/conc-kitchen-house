### D-1-4 · `_ghHydrated` is a ceremony, not a boundary — it flips true even when every hydration fetch failed

- what: `_ghPushFileNow` refuses to publish "not hydrated from cloud yet" — but the flag arms via `Promise.allSettled([...fetch...])` where each fetch already has `.catch(()=>null)`, so it resolves **immediately on network failure**, plus an unconditional 5s `setTimeout`. Mitigated by the visible red sync bar when the boot pull fails, and by the overlay day-union merge — but registry/door_state pushes are whole-file.
- direction: The pull side already owns the pattern — `pullStateFromGitHub`'s `_meta.exported` vs local provenance compare (:10190-10199). Arm `_ghHydrated` only on ≥1 successful settle, or gate the push on the same provenance compare (which is also silent-drift plan E2's shape, DOOR-side).
