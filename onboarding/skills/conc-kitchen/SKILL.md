### Ingredient Weight Conventions

Proteins: kg (cases) or lbs (bags) — match ordering units. Ground beef always in lbs.

Mirepoix vegetables (onions, carrots, celery): always in lbs.

Other non-protein ingredients: grams, rounded to clean numbers (500g, 200g, 1kg).

Liquids: L or mL. Aromatics stored in deli containers (garlic, ginger): qt.

### Portion Size Reference

Protein main: ~6 oz. Stew/soup/curry: ~12 oz. Starch side: ~6–8 oz. Veg side: ~3.5–4 oz. Raw quantities: portions × serving size → cooked yield → raw weight via shrink factor.

### Allergen Detection (Canada Priority 11 + Sensitivity Flags)

The Restriction line is auto-generated by scanning all ingredients against Canada's Priority Food Allergens: Gluten, Soy, Milk, Eggs, Fish, Peanuts, Tree Nuts, Sesame, Mustard, Sulphites, Crustaceans/Shellfish. Plus two sensitivity flags: Nightshades and Spicy.

**Format**: Grouped with specifics, pipe-separated. Example: `Gluten (Soy Sauce, Panko) | Soy (Soy Sauce) | Eggs (Eggs) | Sesame (Sesame Oil)`

Recipes with no detected allergens show "None".

**Key exclusion rules** (to avoid false positives): "egg" in eggplant → skip Eggs; "milk" in coconut/oat milk → skip Milk; "butter" in peanut butter → skip Milk; "cheese"/"cheddar"/"mozzarella" in vegan cheese → skip Milk; "flour" in cauliflower → skip Gluten. Coconut milk/oil IS flagged as Tree Nuts (Canada classification). Margarine is NOT flagged as Milk (commercial margarine is typically dairy-free).

### Dietary Variants

Every main recipe supports Regular, Halal, and Vegan variants. Halal/Vegan notes go in the instruction block as labelled steps (e.g. "FOR HALAL: use halal chicken in place of pork" / "FOR VEGAN: Reserve X lbs before adding meat, bag separately"). Standalone vegan recipes get the `_Vegan` suffix.

### DateTime Corruption in Quantity Cells

Excel auto-converts fractions typed into cells (e.g. `1/2`, `1/4`, `3/4`) into datetime values (e.g. `2023-01-02 00:00:00` for `1/2`). This happens silently when staff edit recipe cards in Excel. When reading recipe files programmatically, always check for `datetime.datetime` values in quantity columns and convert them back: `f"{val.month}/{val.day}"` recovers the original fraction. The March 2026 standardization fixed 59 such cells across ~30 files.

## openpyxl — Production Schedule Working Patterns

The production schedule `.xlsx` files have specific structural quirks that require careful handling. These patterns apply to any programmatic editing of the schedule.

### Merged Cell Handling (`safe_ins()`)
Section header rows (◆▲▼☀🌙⚙📦) are merged across columns A:K. Standard `insert_rows()` corrupts these merges silently. The safe pattern is:
1. **Unmerge** any merged ranges that overlap the insertion point
2. Call `insert_rows()`
3. **Re-merge** at the shifted row positions

All row insertions within a day block should be done **bottom-up** to avoid row-index drift.

### Phantom MergedCell Cleanup
After unmerging, `MergedCell` objects persist in `ws._cells` as read-only entries. Before writing to those cells, delete them explicitly: `del ws._cells[(row_idx, col_idx)]` for all columns beyond the merge master. Without this, writes silently fail or raise `AttributeError`.

### Fill Color Transparency
openpyxl reads ARGB values where the first two hex digits are the alpha channel. Fills written as `00RRGGBB` appear transparent in Excel. Always use `FFRRGGBB` for opaque fills. When auditing, check `cell.fill.fgColor.rgb[:2] == '00'` and replace with `'FF' + rgb[2:]`.

### Theme Color Handling
Reading fills from merged cells is unreliable — non-master cells return incorrect or theme-based color values. Always set the master cell (column A) explicitly from a known fill map, and set remaining cells in the merge range to `PatternFill(fill_type=None)` for header rows rather than copying from the merged range. Use `try/except` returning `PatternFill(fill_type=None)` as a fallback when reading theme colors.

### Row Search Before Insertion
When searching for rows to split or update, collect all target row numbers in a **first pass** before making any insertions. This prevents runaway loops where newly inserted rows match the search condition and trigger repeated insertions.

### Lifecycle Chain Principle
Every advance-produced item needs all lifecycle steps: PREP → COOK → cold-chain SEND PM (if hold ≥ 3d) → PULL AM (day before service) → HEAT → SEND PM hot. Items staying at Bloor (hold ≤ 2d) skip cold-chain rows.

### Cold-Lunch NOTE Pattern
Days where lunch is pre-sent cold get two rows: (1) `SEND AM / NOTE` with item text + site=Rex, (2) `LUNCH / NOTE` with menu-facing name.

### ALT Routing Rule (locked)
ALL small-batch bland/ALT items are cooked and sent from Lansdowne. Lunch ALTs → SEND AM from LAN. Dinner ALTs → SEND PM from LAN.

- White Chilli: vegan pulled from main batch before chicken added (shares cook time)
- Massaman/other stews: separate vegan COOK
